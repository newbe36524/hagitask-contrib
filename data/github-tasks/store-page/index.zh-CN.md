GitHub 任务通过 `gh` CLI 提供专注的远程 GitHub 操作。现有 `arrange-star` 和 `update-repo-description` 命令；后者从操作说明中的 URL 或已选择的可写仓库列表解析目标，并更新明确请求的仓库元数据。
