# Command: publish

Prepare the selected Contrib package for local publication by moving it into the user-selected local Community Packages checkout. The execution context always provides two selected repository paths: the writable Contrib source repository and the local Community Packages destination repository. Use those injected paths as authoritative; do not infer them from repository names, the working directory, or a fixed monorepo layout. Keep the task id and requested semantic version from the operation context; do not invent, omit, or silently replace either value.

1. Read the two selected repository paths from the execution context and verify that both exist, are distinct, and contain the expected repository roots. Use the selected Contrib path as the source and the selected Community Packages path as the destination. Initialize the nested `hagitask` schema checkout if needed. Do not use `gh`, forks, remotes, pushes, commits, or Pull Requests.
2. Run `npm run validate` and `npm test` in the Contrib checkout. Confirm the selected source package, `manifest.taskPresetId`, directory name, and requested version before copying. Any preflight, identity, or version failure stops the operation and leaves the Contrib source untouched.
3. Copy only the package source from `repos/hagitask-contrib/data/<taskId>/` to `data/<taskId>/` in the local Community checkout. Do not copy catalogs, archives, generated output, unrelated packages, or repository-level files. Update the copied package's `manifest.json` to the requested semantic version and preserve its public `$schema` URLs.
4. Run the Community checkout's real validation and tests. If copying or any validation step fails, stop and report the failure; the Contrib source remains unchanged.

Report the task id, old and new versions, copied files, skipped/generated files, Contrib and Community validation exit statuses, and local destination. This command prepares local repository contents only; it does not remove the Contrib source, create a commit, push, Pull Request, merge, or release.
