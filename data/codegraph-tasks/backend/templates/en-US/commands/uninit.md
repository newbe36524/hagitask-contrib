## Command: uninit

Remove the CodeGraph project index from each eligible repository.

1. Require write access and run `codegraph uninit` from each eligible repository root (or the verified no-download CLI equivalent).
2. Report for each repository whether its project index was removed, absent, or could not be removed; verify actual results.
3. Do not uninstall the CLI or agent integrations, and do not remove unrelated project data.
