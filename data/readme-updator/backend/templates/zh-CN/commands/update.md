## 命令：update

刷新每个仓库的源 `README.md`，使其与仓库的索引文件和仓库自身证据一致。只修改存在偏差的内容。

1. 读取 `.hagicode/hagitask/readme-updator/index.md`，并按系统提示的要求检查其键。遇到阻塞时，停止该仓库的处理，不在其中写入任何内容，并继续处理其他仓库。
2. 读取源 `README.md`。若文件不存在，为该仓库报告阻塞：本命令刷新已有的 README，不负责创建。
3. 从仓库自身的文件中收集 README 所依赖的仓库事实，例如用途、命令、配置、路径和链接。不得描述仓库中不存在的功能。
4. 将 README 与索引文件中的需求（必需章节、受众、语气、排除项）以及收集到的事实进行对照：
   - `style: product`：以产品语言描述价值、受众和用法，并将内部实现细节排除在主要描述之外。
   - `style: technical`：描述架构、命令和约定，且以仓库的代码和配置为依据。
5. 若 `public` 为 `true`，删除或改写仓库证据显示为私有的任何密钥、仅限内部的主机或路径，以及链接。
6. 只修改与第 4 步和第 5 步存在偏差的章节。其他每一行都必须逐字节保持不变。
7. 若没有任何偏差，保持 `README.md` 不变，并报告为未变更。
8. 不得编辑任何翻译版 README。若 `multilingual` 为 `true` 且 `README.md` 发生了变更，报告需要执行 `translate` 命令，使翻译版 README 与其保持一致。
9. 按系统提示中的报告规则，逐仓库报告 `README.md` 的变更或未变更情况、任何阻塞以及计数。
