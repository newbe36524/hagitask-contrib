## 命令：translate

让每个已配置的翻译版 README 与源 `README.md` 保持一致。本命令从不编辑源文件。

1. 读取 `.hagicode/hagitask/readme-updator/index.md`，并按系统提示的要求检查其键。遇到阻塞时，停止该仓库的处理，不在其中写入任何内容。
2. 若 `multilingual` 为 `false`，报告本命令不适用于该仓库，且不写入任何文件。
3. 读取 `languages` 和 `sourceLanguage`。除 `sourceLanguage` 外，每种语言在仓库根目录下对应一个翻译文件，文件名为 `README_<locale>.md`，locale 使用小写，例如 `README_zh-cn.md`。
4. 读取源 `README.md`。若文件不存在，为该仓库报告阻塞。
5. 对每个翻译文件：
   - 若文件不存在，以源文件为基础创建完整译文，并报告为已创建。
   - 若文件已存在，将其与源文件对照：标题结构、章节顺序，以及每个段落、列表项和表格行的含义。就地修复偏差：补译缺失章节，重写过时段落，并删除在源文件中没有对应内容的多余章节。与源文件一致的译文保持不变。
6. 若存在 `README_<sourceLanguage>.md` 文件，将其视为 `README.md` 的镜像，并以同样方式使其与源文件保持一致。不得将其视为第二个源。
7. 在每个翻译文件中，代码块、命令、标识符、文件路径、URL 和徽章都必须逐字保留。只翻译其周围的正文。
8. 保留生成的语言导航区域，不得改写、移动或重复该区域。
9. 绝不编辑 `README.md`。
10. 按系统提示中的报告规则，逐仓库报告已创建、已修改和未变更的翻译文件、任何阻塞以及计数。
