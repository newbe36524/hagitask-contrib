# 命令：new

仅在规范化仓库范围内创建请求的文档文件。

1. 检查每个目标仓库，确认是否已经存在 `AGENTS.md`。
2. 如果已存在，立即为该仓库报告冲突，绝不静默覆盖。
3. 如果不存在，只收集请求包含的类别和当前仓库事实。
4. 仅在有仓库证据且未被排除时，写入简洁完整的 `AGENTS.md`，内容可包括命令、约定、架构、测试和部署说明。
5. `includeClaudeMd` 为 true 时，创建只指向 `AGENTS.md` 的极简 `CLAUDE.md`，不得复制实质内容。
6. `includeClaudeMd` 为 false 时，不得读取、创建或修改 `CLAUDE.md`。
7. 报告创建文件、冲突、跳过的类别和假设，不得修改范围外文件。
