# 命令：shrink

在不删除可能仍然有效的信息的前提下，收缩文档，仅保留当前有用的指导。

1. 读取每个目标仓库已有的 `AGENTS.md`，根据当前仓库证据判断各个章节。
2. 保留仍然准确、可执行且属于请求类别的说明。
3. 只删除已确认过时、重复、生成、临时、敏感或明确排除的内容。
4. 对不确定的内容予以保留并报告，不得猜测后删除。
5. 保持 `AGENTS.md` 为实质内容的唯一来源。
6. `includeClaudeMd` 为 true 时，保持 `CLAUDE.md` 为指向 `AGENTS.md` 的极简重定向；为 false 时不得读取或修改它。
7. 报告删除、保留、不确定和跳过的内容，不得修改范围外文件。
