# 命令：incresement update

以增量方式更新现有文档，只修改当前仓库事实要求变化的内容，并保留有效说明。

1. 编辑前读取每个目标仓库已有的 `AGENTS.md`。
2. 将文档中的命令、架构、约定、测试、部署及其他请求类别与当前仓库进行对照。
3. 仅根据当前文件和配置补充缺失内容，或更新已经过时、发生变化的内容。
4. 尽可能保留有效措辞和结构；不得因为未检查某段内容就整体重写或删除。
5. `includeClaudeMd` 为 true 时，只更新 `CLAUDE.md` 中指向 `AGENTS.md` 的极简重定向，不写入实质内容。
6. `includeClaudeMd` 为 false 时，不得读取、创建或修改 `CLAUDE.md`。
7. 报告新增、更新、保留和跳过的内容及假设，所有变更严格限制在规范化范围内。
